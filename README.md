# Project Management API

A backend-focused Project Management System built with Node.js, Express.js, and MongoDB.  
The project provides secure authentication, project handling, task management, and RESTful APIs for managing workflows efficiently.

---

## Features

- User Authentication & Authorization
- JWT-based Protected Routes
- Project Management APIs
- Task Management APIs
- CRUD Operations
- RESTful API Architecture
- Error Handling Middleware
- MongoDB Database Integration
- Scalable Backend Structure

---

## Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/prashant13092004/Project-Management.git
```

### Navigate to the Project Directory

```bash
cd Project-Management
```

### Install Dependencies

```bash
npm install
```

---

## Environment Variables

Create a `.env` file in the root directory and add:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
ACCESS_TOKEN_SECRET=your_access_token_secret
REFRESH_TOKEN_SECRET=your_refresh_token_secret
```

---

## Run the Project

```bash
npm run dev
```
